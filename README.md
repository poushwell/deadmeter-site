# Deadmeter

Internet content tracking with confidence intervals.
deadmeter.com

## Stack

Next.js (App Router) · Tailwind CSS · Vercel · Supabase · Resend · Lemon Squeezy

## Local dev

Requires `.env.local` from project owner.

```bash
npm install
npm run dev
```

## Workflow

Feature branches only. No direct push to main. Pavel reviews PRs.
Branch naming: `feature/name`, `fix/description`, `docs/description`.
